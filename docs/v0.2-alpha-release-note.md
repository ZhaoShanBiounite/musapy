# musapy v0.2.0-alpha

**第二个 alpha 发布** — 完整算子面 + GPU 性能优化 + 正确性修复。

相对 v0.1-alpha（核心运行时 + 仅 add 算子），本版本实现 v0.2 计划
（`docs/archive/v0.2-alpha-plan-zh.md`）全部 6 个功能阶段，并叠加 P0–P6 性能与
正确性工作（详见 `benchmark/analysis-followup-2026-08-04.md`）。

---

## 主要功能

### 算子面（44 个导出函数 + Array 方法）

- **stride-aware kernel ABI**（`_v2`）：N 维 stride + 广播（NumPy 规则，
  stride=0 零拷贝广播）
- **类型提升**：JAX 风格 type-based；`i64 + f32 → f32`（整数不因位宽升级
  浮点）、GPU 全运算窄优先（`f32 + f64 → f32`）
- **elementwise**：add/sub/mul/div/pow + sin/cos/exp/log/abs/sign/neg +
  clamp + `astype`（25 个 cast 组合）+ 运算符重载
- **comparison**：eq/ne/lt/gt/le/ge，输出 bool 数组
- **reduction**：sum/prod/max/min/mean（axis/keepdims）+ argmax/argmin
  （int64 索引）+ cumsum（单轴容量上限 256³ ≈ 16.7M 元素）
- **init**：zeros/ones/full/eye/arange/linspace/zeros_like/ones_like
  （device/dtype 5 级解析链 + 首次创建报错）
- **indexing**：transpose/permute/flip/slice/index_select（view 零拷贝）+
  gather/scatter/contiguous（copy，GPU kernel）
- 每算子 CPU fallback + mock stub（无 GPU 可测）

### 性能（MTT S4000 实机，1M f32）

| 算子 | v0.1/初版 | v0.2 优化后 |
|---|---|---|
| gather / scatter | ~10 ms（每次调用同步校验） | **0.178 / 0.240 ms**（~50×） |
| 全局 sum/prod/max/min/mean | 0.129–0.131 ms | **0.084–0.086 ms** |
| 2D 256×256 axis 缩减 | 0.122–0.158 ms | **0.053–0.056 ms** |
| contig(transp) | 0.240 ms（33 GB/s） | **0.063 ms**（≥2M 规模 220+ GB/s） |
| add 16M | 0.326 ms（589 GB/s） | **0.310 ms**（620 GB/s，float4 向量化） |

- launch 地板实测 ~45 µs（driver 提交路径，1M 规模数字受其主导；
  16M→64M 斜率 683 GB/s ≈ DRAM 峰值 89%）
- 死代码清理：kernel 符号 179 → 176（v1 兼容符号移除）

### 语义变更（相对 NumPy / v0.1）

1. **GPU 越界错误延迟报错**：gather/scatter 索引越界在同步时抛
   `ShapeError`（`tolist()`/`item()`），流不毒化、越界条目跳过
2. **标量不自动广播**：二元/比较操作数必须为 Array（`clamp` 的
   lo/hi 除外）；`gather`/`scatter` 的 indices 需显式 `dtype=ms.int64`
3. **类型提升**：`i64 + f32 → f32`（int64 会被 cast 成 f32，大整数有
   精度损失——计划既定"GPU 窄优先"语义）

### 正确性修复

- **cumsum 分层扫描**（P0）：axis_len > 65536 时结果错误 + smem 越界
  → 修复并扩至 256³/轴
- 转置视图指针 offset 未调整的隐患（P1）
- benchmark 方法学：log 双 kernel 计时假象等（P5）

## 技术栈

| 层 | 技术 |
|---|---|
| Python 前端 | PyO3 0.23 + maturin |
| Rust 后端 | Cargo workspace（musapy-core / musapy-ops / musapy-python） |
| GPU kernel | MUSA C（`.mu`），mcc 编译，179 → 176 个 extern 符号 |
| 内存策略 | deferred-free（默认）/ stream-ordered（feature gate） |

## 安装

```bash
pip install musapy-0.2.0a0-*.whl
```

或从源码构建：

```bash
git clone https://github.com/ZhaoShanBiounite/musapy.git
cd musapy
pip install -e .
```

**前置条件**：Python >= 3.9、Rust stable（edition 2024）、MUSA SDK 3.x+
（`MUSA_HOME`）

## 已知限制

- 标量不自动广播（需包成 1 元素 Array）；`gather/scatter` indices 需
  显式 int64
- `axis=tuple` 多轴归约 → v0.3
- 高级索引（boolean mask / fancy indexing）→ v0.3+
- 复数 reduction → v0.3；数学库 ops（linalg/random/fft/sparse）→ v0.3-alpha
- DLPack / NumPy 协议（`__array_ufunc__` 等）→ v0.4-beta
- MUSA Graphs capture → v2；MCCL 分布式 → v2
- wheel 构建环境：CPython 3.10 / Linux x86_64
