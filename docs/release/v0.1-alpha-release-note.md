# musapy v0.1.0-alpha

**首个 alpha 发布** — 核心运行时 + 最小算子端到端验证。

---

## 主要功能

### 核心数据结构
- **Device**：支持 `"cpu"` / `"musa:N"` 标识，5 级优先级解析链（参数 > context > 输入 > 全局默认 > auto-probe）
- **Dtype**：15 种数据类型（bool / int8-64 / uint8-64 / float16/32/64 / bfloat16 / complex64/128）
- **Stream**：per-device 异步执行流，支持优先级、synchronize、poison 检测
- **Array**：绑定 device + stream + layout 的多维数组，支持命名
- **Buffer / BufferRef**：读写引用分离，支持 `__restrict__` 无别名保证

### 算子
- `ms.add(a, b, out=None)` — 逐元素加法（float32 / float64）
- `a + b` dunder 等价写法
- `out=` 参数 + 自动跨 stream wait（ADR L1-8）
- alias 检测：`out` 与输入相同抛 `MemoryError`

### 内存管理
- deferred-free 默认路径（兼容 MUSA SDK 3.x / 4.x / 5.x）
- stream-ordered 可选路径（`--features stream-ordered`，需 SDK 5.x+）
- 内存统计：`ms.memory_summary()` 显示 allocated / cached / peak

### 解析与上下文
- `ms.set_default_device()` / `ms.set_default_dtype()` — 全局默认
- `with ms.device(...) / ms.dtype(...) / ms.stream(...)` — context manager
- thread-local 隔离：子线程继承父线程快照，之后解耦
- 未设默认时首次创建 Array 抛 `DeviceNotConfiguredError`（ADR L0-9）

### 可观测性
- `ms.device_summary()` — 设备名称、arch、VRAM、CU 数
- `ms.set_debug(True)` / `with ms.debug():` — OpContext 记录 python_frame
- Resolution feedback：`repr(a.device)` 显示解析来源

### 异常层级

```
MusapyError(Exception)
├── DeviceError(RuntimeError)
│   └── DeviceNotConfiguredError
├── DtypeError(TypeError)
├── ShapeError(ValueError)
├── MemoryError
│   └── OutOfMemoryError
├── StreamError(RuntimeError)
├── KernelError(RuntimeError)
└── InteropError(RuntimeError)
```

## 技术栈

| 层 | 技术 |
|---|---|
| Python 前端 | PyO3 0.23 + maturin |
| Rust 后端 | Cargo workspace（musapy-core / musapy-ops / musapy-python） |
| GPU kernel | MUSA C（`.mu`），mcc 编译 |
| 内存策略 | deferred-free（默认）/ stream-ordered（feature gate） |

## 安装

```bash
pip install musapy-0.1.0a0-cp310-cp310-manylinux_2_34_x86_64.whl
```

或从源码构建：

```bash
git clone https://github.com/ZhaoShanBiounite/musapy.git
cd musapy
pip install -e .
```

**前置条件**：Python >= 3.9、Rust stable、MUSA SDK 3.x+（`MUSA_HOME`）

---

## 已知限制

- 仅实现 `add` 一个算子（完整 elementwise/reduction/init 在 v0.2-alpha）
- 不支持 broadcast（v0.2-alpha）
- 不支持 DLPack / NumPy 互操作（v0.4-beta）
- 不支持 MUSA Graphs capture（v2）
- 不支持分布式 MCCL（v2）
- wheel 仅构建 CPython 3.10 / Linux x86_64
