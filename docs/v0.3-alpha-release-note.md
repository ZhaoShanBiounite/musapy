# musapy v0.3.0-alpha

**第三个 alpha 发布** — 数学库（linalg / random / fft / sparse）+ reduction 补全 + 高级索引。

相对 v0.2-alpha（完整算子面），本版本实现 v0.3 计划
（`docs/v0.3-alpha-plan-zh.md`）全部 8 个功能阶段（Phase 1–8），并叠加
P0–P3 / P-FFT / P-A1–A4 性能与正确性工作。数学库算子走 MUSA SDK 原生轮子
（muBLAS / muSOLVER / muRAND / muFFT / muSPARSE），**GPU-only**（ADR-003 003-D4）。

---

## 主要功能

### 数学库（MUSA-X FFI，GPU-only）

- **linalg**（muBLAS + muSOLVER）：matmul / dot / solve（getrf+getrs，
  奇异检测设备端化）/ lu / qr（geqrf+orgqr）/ svd（gesvd ALL 模式）
- **random**（muRAND）：rand / randn / uniform / normal / bernoulli，
  seed 可复现（per-device 缓存单一流，003-D9）
- **fft**（muFFT）：fft / ifft / rfft（axis=-1，n 截断/补零，norm 三值；
  2D+ batched PlanMany，P-FFT-1）
- **sparse**（muSPARSE）：csr_matrix + spmv / spmm / toarray（`@` 收
  Array/ndarray/list；描述符缓存，P-A3）

### 补全（v0.2 推迟项兑现）

- **reduction axis=tuple**：sum/prod/max/min/mean 逐轴迭代 +
  argmax/argmin transpose+合并轴（扁平索引，NumPy 2.0+ 语义）+ arg* 补 keepdims
- **复数 reduction**：sum/mean/prod 支持 c64/c128（分量并行归约，
  c64 sum 1M 214ms→0.11ms ~1900×）；max/min/arg* 复数显式 DtypeError
- **复数 elementwise**：add/sub/mul/div/neg/abs + eq/ne（Phase 5 落地）；
  `ms.array([1+2j])` 推断 complex128
- **高级索引**：boolean mask（等形 + 前 md 维广播）+ fancy indexing
  （坐标配对/索引形状广播/N-D/负索引），恒 copy；越界抛 Python 内置 IndexError

### 性能（MTT S4000 实机）

| 项 | 优化前 | 优化后 |
|---|---|---|
| fft 2D 64×4096 | 6.43 ms（逐行） | **0.26 ms**（batched，P-FFT-1 24.5×） |
| spmv 2000² d=0.01 | 0.67 ms | **0.061 ms**（描述符缓存，P-A3 11×） |
| 复数 sum 1M（c64） | 214 ms（naive） | **0.11 ms**（分量并行 ~1900×） |
| solve(1024) | 51 ms | **23.4 ms**（奇异检测设备端化 P0） |
| argmax 64M | 1.59 ms | **1.485 ms**（partial 连续读，P-A1） |
| elementwise 峰值带宽 | — | **696 GB/s**（64M） |
| f32 matmul 峰值 | — | **13.9 TFLOPS**（n=2048） |

### 语义与错误模型

1. **越界高级索引抛 Python 内置 IndexError**（NumPy 兼容，003-D3 扩展；
   非 MusapyError 子类）
2. **复数排序归约拒绝**：max/min/argmax/argmin 对复数抛 DtypeError（无全序）
3. **混合 basic+fancy 索引**（`a[1:, [0,2]]`）抛 NotImplementedError（v0.4）
4. **算子族归属规则**（003-D4 澄清）：v0.2 算子族后续 dtype/形态扩展保留
   CPU 路径；v0.3 新算子族（linalg/random/fft/sparse）一律 GPU-only
5. **字符串 dtype 语法**：所有 `dtype` 参数接受字符串短别名
   （`'f32'`/`'f64'`/`'i8'`-`'i64'`/`'u8'`-`'u64'`/`'f16'`/`'bf16'`/
   `'c64'`/`'c128'`/`'b1'`）、字符串全名（`'float32'` 等，大小写不敏感）或
   Dtype 常量（`ms.float32`，向后兼容）；`a.dtype` 可与字符串比较
   （`a.dtype == 'f32'`），`astype`/`ms.dtype(...)`/`set_default_dtype` 同理

## 安装

```bash
pip install musapy-0.3.0a0-*.whl
```

或从源码构建：

```bash
git clone https://github.com/ZhaoShanBiounite/musapy.git
cd musapy
pip install -e .
```

**前置条件**：Python >= 3.9、Rust stable（edition 2024）、MUSA SDK 3.1+（`MUSA_HOME`）
**运行依赖**：muFFT 依赖 `libmtfft-device-*.so`（按 arch 变体，DT_NEEDED 传递加载）

## 已知限制

- 数学库算子 GPU-only（003-D4）；CPU 调用抛 DeviceError
- fft axis=-1 起步（fftn/多轴/irfft → v0.3 后期）；sparse 只做 csr_matrix
  （coo → v0.3 后期）
- 高级索引当前 GPU 走 host fallback（mcc 不支持指针数组 kernel 参数；
  `adv_gather/nonzero` kernel 已声明，优化待接入）
- 复数归约仅支持 sum/mean/prod（max/min/arg* 永久拒绝）；partial/small_axis
  复数路径已并行化
- 混合 basic+fancy 组合索引 → v0.4；DLPack / NumPy 协议 → v0.4-beta
- SDK 3.1.0 限制（f64 慢 4×、geqrf/gesvd 低效、randn f64 ~3 GB/s、
  memcpy2D bug 等）见 `docs/sdk-3.1.0-limitations.md`
- wheel 构建环境：CPython 3.10 / Linux x86_64
